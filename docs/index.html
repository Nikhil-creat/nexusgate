Features

Zero-alloc proxy

Pooled buffers, weighted least-connections balancing and a background health probe that revives failed nodes.

MCP and A2A guard

Stops agent loops and enforces token budgets from X-Agent-ID and X-Max-Loops.

Semantic cache

Prompts at cosine 0.96 or higher skip the LLM.

CNN threat filter

Payload scan with an ONNX seam; signature scanner works today.

Distributed limits

Redis Lua token bucket, fail-open or fail-closed, X-RateLimit headers.

Zero-trust auth

RS256 JWT with cached JWKS and rotation. Set JWKS_URL.

Reliability

Circuit breaker on real status codes and latency, graceful shutdown, request IDs, timeouts.

Security headers

HSTS, nosniff, strict CORS allow-list and a 1 MB payload cap.

Observability

Prometheus metrics, Jaeger and an OTel collector in Compose.
