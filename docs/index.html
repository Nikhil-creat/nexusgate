Features

Zero-alloc proxy

Pooled buffers and weighted least-connections balancing with passive health.

MCP and A2A guard

Stops agent loops and enforces token budgets from X-Agent-ID and X-Max-Loops.

Semantic cache

Prompts at cosine 0.96 or higher skip the LLM entirely.

CNN threat filter

Payload scan seam for ONNX; signature scanner works out of the box.

Distributed rate limits

Redis Lua token bucket with fail-open or fail-closed modes.

Zero-trust auth

RS256 JWT with cached JWKS and key rotation. Set JWKS_URL to enable.

Circuit breaker

Closed, open and half-open states over a rolling 10 second window.

Observability

Prometheus metrics, Jaeger tracing and an OTel collector in Compose.

Groq assistant

A built-in chatbot that answers questions about the gateway.
